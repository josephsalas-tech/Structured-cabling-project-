# Structured Cabling Project – Residential Network Infrastructure Build

## Overview

This project documents the installation of structured Ethernet cabling throughout my home in order to create a centralized and scalable network infrastructure similar to small business and enterprise environments.

The objective of this project is to transition from consumer-style networking to a permanent wired infrastructure capable of supporting:

- High-speed wired networking
- Centralized switching
- Wireless access points
- Future PoE security cameras
- Homelab and server infrastructure
- Wall-mounted TVs with hardwired Ethernet connectivity

This project combines both **physical low-voltage installation skills** and **network infrastructure planning**.

---

# Project Goals

- Run Cat5e Ethernet cabling through interior walls
- Provide wired network access to multiple rooms
- Centralize all networking equipment into a dedicated closet
- Prepare for future rack-mounted infrastructure
- Reduce reliance on Wi-Fi for stationary devices
- Build hands-on experience with structured cabling practices

# Challenges & Lessons Learned

## Key Lessons
- Planning cable paths before drilling significantly reduces installation complexity
- Centralized cable management improves long-term scalability
- Labeling cable runs is critical for troubleshooting and maintenance
- Wired infrastructure greatly improves reliability compared to Wi-Fi-only deployments
